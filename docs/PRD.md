# Agemo — Product Requirements Document

> **Emotional Hook**: A Solana project burned $8K on referral rewards but couldn't tell which campaign drove retention.

## Problem Statement
Growth campaigns on Solana are manually managed. No feedback loop between performance and strategy.

## Solution Overview
Autonomous AI growth loop agent via Torque MCP. Analyze → Optimize → Execute — full loop.

## Core Features (MVP)
1. Campaign creation via Torque MCP
2. User journey tracking
3. AI optimization engine
4. Autonomous execution (adjust campaigns)
5. Dashboard showing AI decision trail

## Success Metrics
- All SDK features demonstrably integrated
- Demo flow works end-to-end

## Out of Scope
- ❌ Custom reward tokens
- ❌ Multi-chain campaigns
