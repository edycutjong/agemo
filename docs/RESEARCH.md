## Mission
Build AI-powered growth applications using **Torque's MCP (Model Context Protocol) server** to create autonomous growth loops, referral engines, and quest/campaign systems on Solana.

## Track Scope & Focus Areas
- **Growth Loops** — automated referral, retention, and engagement campaigns
- **AI Agent Integration** — MCP-native tools for AI agents to manage campaigns
- **Quest Systems** — on-chain verification of user actions
- **Reward Distribution** — automated token/NFT reward pipelines
- **Analytics** — campaign performance tracking and optimization

## SDK / Integration Primitives
- `@torque-labs/torque-mcp` — MCP server for AI agent integration
- Campaign creation and management APIs
- Quest/challenge definition and verification
- Reward distribution (SPL tokens, NFTs)
- User journey tracking and analytics
- Referral link generation and attribution

## Submission Requirements
- Working integration with Torque MCP server
- Public GitHub repository
- Demo video showing MCP integration in action
- Must demonstrate autonomous campaign management
