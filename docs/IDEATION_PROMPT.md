## Thinking Framework

### Standard Analysis
- Only ~6 submissions for 3 prizes. **Near-guaranteed win with quality.**
- MCP (Model Context Protocol) is bleeding-edge — most Solana devs don't know it yet.
- Growth/referral tooling is a REAL business need (not just hackathon theater).
- What growth problems do Solana protocols ACTUALLY face? (user onboarding, retention, referral fraud)
- Can you build an AI agent that autonomously runs growth campaigns?

### Anti-Pattern Analysis
- **Docs Example Trap**: If Torque docs show "create a referral campaign," don't just build a referral page.
- **MCP Secret Weapon**: The MCP server means AI agents can AUTONOMOUSLY manage campaigns. This is the unlock — build for agents, not just humans.
- **Growth Loop Must Be Viral**: A campaign that doesn't self-amplify isn't a growth loop.

### Emotional Hook Test (Mandatory)
For EACH idea, write "A [specific person]..." framing the problem as a real growth crisis.

## Output Format

Rank highest to lowest winnability. Every idea must have a clear visual demo moment.

**Never 🔴 Docs Distance. Never fail Emotional Hook. Prefer Narrow+Deep.**
